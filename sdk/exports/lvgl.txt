# The firmware's LVGL, for ELF apps. Apps use the OS's LVGL instance (its
# display, screens and globals), so they call it rather than linking their own.
# Format: see viper.txt.
#
# The first set is the LVGL API the built-in apps, the stages and ui use, minus
# what an app shouldn't touch: LVGL's allocator (apps use malloc, which is
# tracked), the display and input devices (apps get input through loop()),
# screen loading, lv_async_call (it calls back into the app later), and font and
# image decoder internals. Exporting a function costs a table entry, and the
# function's code if nothing in the firmware uses it yet. Add what apps need.
#
# Names with "= viper_elf_..." go through components/system/src/elf_lvgl.cpp,
# which tracks what the app creates outside its container (objects, timers,
# animations, event callbacks) so closing the app deletes it. Every widget's
# _create() is tracked; add a VIPER_ELF_TRACKED_CREATE() there for a new one.
