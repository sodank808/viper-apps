# Viper's own functions for ELF apps: the API in sdk/include/viper_app.h,
# implemented in components/system/src/elf_app.cpp, elf_audio.cpp and
# elf_link.cpp (link play, sdk/include/viper_link.h).
#
# tool/gen_exports.py turns the lists in this folder into the loader's export
# table, and tool/check_app_elf.py checks apps against them. A line is a name the
# app calls, optionally followed by "= <firmware symbol>" when the firmware
# provides it under another name, and by "if CONFIG_<option>" when it's only
# exported from firmware built with that option.
#
# Every name here is ABI: an installed app that calls it stops loading if it
# goes. One function per job (docs/plans/game_api_consolidation.md).
